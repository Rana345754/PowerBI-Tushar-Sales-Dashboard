# Sales Analytics Dashboard – Power BI

## Project Overview

An interactive Power BI dashboard created to analyze sales,
profit, customers, products and order performance.

## Tools Used

- Power BI
- Power Query
- DAX
- Excel

## Key KPIs

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Average Order Value

## Data Preparation

- Removed blank records
- Corrected data types
- Cleaned date columns
- Removed unnecessary columns
- Created calculated columns where required
- Created relationships between tables
